# RSS Overview

A Next.js + Tailwind CSS v3 starter for an RSS shakha location directory.

## Stack

- Next.js 14
- TypeScript
- Tailwind CSS v3
- MongoDB driver

## Run locally

```bash
npm install
npm run dev
```

## Notes

- Current shakha data is stored in `src/data/shakhas.ts`.
- The homepage includes a top navbar, a small left sidebar with 5 placeholder links, and a clickable India map-style section.
- MongoDB is prepared through `src/lib/mongodb.ts` for later admin-backed data storage.
